07 / Methodology & controls

Analytical control framework

A repeatable review loop for updating the forecast without mixing incompatible data.

DEFINEFix the target: worldwide Day 1 gross, local currency and market scope.
MEASURECapture the source, publication time, fetch time and reported coverage.
ANALYSEReconcile duplicate reports, block seats, territories and gross/net definitions.
IMPROVEUpdate only after validating source changes and scope consistency.
CONTROLPreserve timestamps, retain last successful data and flag stale observations.
Data caveat: this dashboard displays the contents of data.json. Charts redraw when that file changes. Forecast scenarios remain authored values unless an explicitly enabled and configured forecastModel is present. A page refresh does not fetch source websites or change data.json.
